# Glossary

- **Session** — one agent, one task, one report.
- **Sweep** — one prompt fanned out to one session per open item; returns one board.
- **Bounds** — an agent's never-do list, in its file under `## Bounds`.
- **Hook** — a rule enforced by the runtime before or after a tool call; cannot be talked past.
- **Reinforcement** — a pull request that moves a repeated pattern into the fleet.
- **Measured / inferred** — whether a claim about the outside world has a command and output behind it.
