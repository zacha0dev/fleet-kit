# Scorecards

Each rubric line scores 0, 1 or 2, so a full session is out of 12. A line that does not apply to the session is marked `—` and lowers the maximum by 2 (for example, a triage session writes no code, so line 3 is `—` and the total is out of 10).

Rows whose session starts with `seed:` were written with the repository to show the format. They are examples, not scored runs.
